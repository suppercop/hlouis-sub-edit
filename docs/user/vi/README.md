# HLouis Sub Edit — Hướng dẫn sử dụng (Tiếng Việt)

Chào mừng đến với **HLouis Sub Edit** — trình biên tập phụ đề viết bằng Rust tối ưu tốc độ cao, giữ nguyên bố cục và thói quen thao tác quen thuộc của Aegisub 3.2.2 / 3.5.1.

## Bố cục 4 khung chuẩn Aegisub 3.2.2

1. **Trên-Trái — Khung Video & Công cụ Typeset trực quan**: Hiển thị RGBA chuẩn màu kèm chỉ báo Keyframe, đủ 7 công cụ Typeset (Standard, Drag, Rotate Z, Rotate XY, Scale, Rectangular Clip, Vector Clip hỗ trợ chuyển đổi `b`/`s`), tua từng khung hình mượt mà.
2. **Trên-Phải — Khung Âm thanh (Waveform & Spectrum)**: Hiển thị dạng sóng và phổ tần FFT (bảng màu Icy Blue, Green hoặc theo Theme) với bộ nhớ đệm theo mức zoom, hỗ trợ kéo timing và chia âm tiết Karaoke.
3. **Giữa-Phải — Ô chỉnh sửa phụ đề (Subtitle Edit Box)**: Thanh thuộc tính dòng (Comment, Layer, Style, Actor, Effect, Lề L/R/V, chế độ Thời gian/Khung hình), tô màu cú pháp thẻ ASS, hỗ trợ gõ tiếng Việt Telex/VNI an toàn với IME và thanh định dạng nhanh.
4. **Dưới — Bảng phụ đề ảo hóa (Subtitle Grid)**: Cuộn mượt trên 200.000 dòng, hiển thị màu CPS, cảnh báo trùng thời gian (Overlap), dòng đang hiển thị trên khung hình và menu chuột phải tích hợp **HLouis Tools**.
