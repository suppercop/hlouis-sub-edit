# HLouis Sub Edit — User Guide (English)

Welcome to **HLouis Sub Edit**, a native Rust subtitle editor built for speed and Aegisub 3.2.2 / 3.5.1 workflow familiarity.

## Classic Aegisub 3.2.2 Workspace Layout

HLouis Sub Edit preserves the classic four-pane workspace layout so experienced fansubbers feel at home immediately:

1. **Top-Left — Video Display & Visual Typesetting Tools**: True-colour RGBA preview with keyframe indicator, 7 visual tools (Standard, Drag, Rotate Z, Rotate XY, Scale, Rectangular Clip, Vector Clip with `b`/`s` spline conversion), and frame-accurate scrubbing.
2. **Top-Right — Audio Display (Waveform & Spectrum)**: Hardware-cached waveform and tiled FFT spectrogram (Icy Blue, Green, or Theme palette) with lead-in/lead-out markers and syllable karaoke timing.
3. **Middle-Right — Subtitle Edit Box**: Metadata strip (Comment toggle, Layer, Style, Actor, Effect, Margins L/R/V, Start/End/Duration in Time or Frame mode), ASS syntax-highlighted editor, IME-safe Vietnamese Telex/VNI input, and formatting toolbar.
4. **Bottom — Virtualised Subtitle Grid**: Smooth 200,000+ line virtual scrolling with CPS colour coding, overlap indicators, active/selected/visible-on-frame highlighting, and right-click context menu including the **HLouis Tools** submenu.
