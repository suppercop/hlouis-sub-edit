FFmpeg corresponding source notice
==================================

This distribution bundles unmodified FFmpeg shared libraries
(avcodec-63.dll, avformat-63.dll, avutil-61.dll, swscale-10.dll,
swresample-7.dll), version n9.0.2-982-g836df4e858, built by
BtbN/FFmpeg-Builds (release/9.0, variant win64-lgpl-shared-9.0) without
--enable-gpl and without --enable-nonfree.

    https://git.ffmpeg.org/ffmpeg.git  (mirror: https://github.com/FFmpeg/FFmpeg)
  - Build scripts and configuration used to produce the binaries:
    https://github.com/BtbN/FFmpeg-Builds
  - The exact binary archive used (SHA-256
    F7BA27E7986A2D0835881E742A682DEC17896F6DC2CDCF9E596F043D2763D894):

version. hlouis-sub-edit links to FFmpeg only dynamically (through
ffms2.dll).

dynamically linked; its source is the vcpkg port listed in THIRD_PARTY.md.
